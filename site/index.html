A fast LRC lyrics parser and writer for .NET, with word timing, duet voices and diagnostics instead of exceptions.

dotnet add package ModernLrc

Get startedAPI reference

ModernLrc reads plain and Enhanced LRC, looks up the line for a playback position, and writes documents back out. It targets .NET 10 and .NET 11, is Native AOT compatible and trim-safe, and has no dependencies outside the BCL. The code below was compiled and run against the library; the output is what it printed.

01

Text in, typed lines out

Metadata, timestamps and text come back as immutable records. A line with several timestamps becomes one line for each, sorted by time. Malformed input is reported as diagnostics with a code, line and column, and parsing carries on.

Diagnostics reference

02

Karaoke, word by word

Enhanced LRC gives every word its own timestamp. Find the line at the playback position, then light up the words as they are sung.

Playback

03

Duets keep their voices

Male, female and duet markers carry forward to the lines that follow, so every line already knows who sings it.

Voices

04

Out as it came in

Edit a parsed document and write it back: offsets, grouped timestamps, voices and word timing survive. Parsing the result gives an equal document, within the documented round-trip limits.
